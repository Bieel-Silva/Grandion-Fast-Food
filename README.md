# 🍔 Grandion Fast Food

Sistema web para pedidos online de fast food, desenvolvido com **ASP.NET Core MVC**.  
O projeto permite que usuários naveguem pelo cardápio, adicionem itens ao carrinho e realizem pedidos de forma prática e intuitiva.

---

## 🚀 Funcionalidades

- ✅ Catálogo de produtos (lanches, acompanhamentos, bebidas, sobremesas)
- ✅ Adição de itens ao carrinho
- ✅ Cálculo automático do valor total do pedido
- ✅ Gestão de pedidos
- ✅ Layout responsivo
- ✅ Arquitetura organizada em camadas (MVC + Services + Repositories)
- ✅ Banco de dados com migrations (EF Core)

---

## 🛠 Tecnologias Utilizadas

| Tecnologia | Descrição |
|----------|-----------|
| ASP.NET Core MVC | Framework Web |
| C# | Linguagem backend |
| Entity Framework Core | ORM para acesso ao banco |
| SQL Server | Banco de dados |
| Bootstrap | Layout e responsividade |
| Razor Pages | Views e componentes |
| Dependency Injection | Arquitetura |
| LINQ | Manipulação de dados |
